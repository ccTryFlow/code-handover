# Tree-sitter grammar resources

These WASM grammars are bundled as Electron runtime resources:

- `tree-sitter-php.wasm`: copied from `tree-sitter-php@0.24.2`
- `tree-sitter-go.wasm`: copied from `tree-sitter-go@0.25.0`
- `tree-sitter-java.wasm`: copied from `tree-sitter-java@0.23.5`
- `tree-sitter-python.wasm`: copied from `tree-sitter-python@0.25.0`
- `tree-sitter-javascript.wasm`: copied from `tree-sitter-javascript@0.25.0`
- `tree-sitter-typescript.wasm`: copied from `tree-sitter-typescript@0.23.2`
- `tree-sitter-tsx.wasm`: copied from `tree-sitter-typescript@0.23.2`
